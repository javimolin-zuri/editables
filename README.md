# Convertidor HTML ⇄ Illustrator (con biblioteca en GitHub)

## Puesta en marcha
1. Crea un repositorio **público** para la herramienta y sube `index.html`. Activa GitHub Pages (Settings › Pages › Deploy from branch › main / root).
2. Crea otro repositorio **privado** para tus editables (así tus diseños no quedan públicos).
3. En GitHub › Settings › Developer settings › Fine-grained tokens: crea un token limitado al repositorio privado, con permiso **Contents: Read and write**.
4. Abre tu página de GitHub Pages › pestaña «Mi biblioteca» › «Conexión con GitHub» y completa usuario, repositorio, rama, carpeta base y token.

El token se guarda solo en el localStorage de tu navegador (nunca en el repositorio).
