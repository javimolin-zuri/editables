Convertidor HTML ⇄ Illustrator

Sube tu lámina en HTML y obtén un archivo vectorial editable (capas, textos vivos, formas, imágenes). También puedes hacer el camino inverso.

Almacenamiento del repositorioSin conexión

  • Cada elemento queda como capa propia (se ven en el panel Capas de Illustrator) y cada línea de texto como texto editable.
  • En Illustrator: abre el SVG → Archivo › Guardar como → .ai o PDF con «Conservar capacidades de edición de Illustrator». Esa es la ruta para obtener un PDF/AI editable.
  • Las tipografías no viajan dentro de Illustrator: instala las fuentes que aparecen abajo (se extraen de tu HTML) antes de abrir el SVG.
  • No se convierten: transformaciones (rotate/scale), filtros CSS, pseudo-elementos y sombras de texto.

  • .ai: se lee a través de su contenido compatible con PDF. Cada página detectada = una mesa de trabajo, en orden, dentro de un solo HTML. Revisa que el número de mesas coincida con el de tu archivo; si faltan, vuelve a guardar en Illustrator con «Crear archivo compatible con PDF» activado.
  • Por esta vía las capas de Illustrator no se conservan (el PDF las aplana en grupos por orden de pintado). Los textos se mantienen como texto, pero con fuentes subconjunto (solo los caracteres usados). Si necesitas capas exactas, exporta desde Illustrator a SVG y sube ese archivo.
  • El HTML resultante contiene el SVG en línea: textos, trazados, grupos y capas (ids) siguen siendo elementos editables del código. Si el SVG trae fuentes embebidas, se conservan.
